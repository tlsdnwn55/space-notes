## ✍️ 새 마크다운 스터디 노트 추가하는 방법

`D:\space-notes\src\content\docs\` 폴더에 `.md` 파일만 작성하고 `git push` 하면 끝납니다!

```bash
# 1. 원하는 카테고리 폴더에 마크다운 파일 생성
D:\space-notes\src\content\docs\frontend\my-new-study.md

# 2. 커밋 후 깃허브 푸시 (자동으로 배포 진행됨)
git add .
git commit -m "docs: 새 스터디 노트 추가"
git push origin main
```
